# 内页手机布局与动效验收 · 2026-10-25

检查七个首页入口：求学时光、荣誉收藏、实习经历、研究手记、AI 实验室、志愿实践、随笔；另检查“关于我”及随笔文章、AI 项目详情。保留天空延伸的纸面、宋体标题、图像入口和半藏圆球导航。

## 修复

- 最窄屏的关于页恢复文字容器，避免 `column-reverse` 与 `display:contents` 叠加造成说明和主介绍倒序。
- 固定顶栏与正文跳转共用高度变量；键盘跳到正文后，手机正文顶部在 62 px，标题在 100 px，未被顶栏遮挡。
- 圆球仅保留球体焦点环；导航、荣誉图片、写作便签的悬停装饰限定精细悬停指针，避免触摸后的残留样式。正常手机正文从 64 px 开始，半藏圆球右边界为 24 px；键盘展开后为 57 px，仍在预留区域内。
- 证书关闭、翻页及原图入口达到 44 px 操作高度。短横屏采用左图右说明；844 × 390 下图片区域由 104 px 增至 324 px，标题、页码和操作控件独立排布，多页证书切换正常。
- 证书 Portal 单独遵从减少动态设置，禁用动画及过渡，保留弹窗居中位移。
- 六张 AI 详情图均为 1080 × 675，加入真实尺寸属性预留布局空间；图片保持响应式比例。未进行网络节流或 CLS 性能评分。
- 平衡介绍语、研究副标题、实践标题、项目详情标题和随笔标题换行，避免窄屏末行仅剩一个字。
