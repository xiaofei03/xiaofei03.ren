## 动效与输入

手机不再叠加姓名缩小、肖像位移和绳索视差，保留 3 秒人像入场与随笔淡入。装饰 hover 限定为精细指针设备，键盘轻摆限定 `:focus-visible`，避免触摸焦点触发悬停摆动。主按钮保留至少 44 px 高度。

强吸附不再由“所有场景都必须刚好一屏”决定。长场景利用浏览器原生 oversized snap area 行为，完整内容可读；参见 [W3C CSS Scroll Snap §5.2.2](https://www.w3.org/TR/css-scroll-snap-1/#snap-overflow)。滚动过程中不拦截触摸或滚轮。
